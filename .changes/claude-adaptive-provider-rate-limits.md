- Prime Agent now paces requests to each provider automatically: every model request waits for a permit from a budget shared by all sessions and subagents of the daemon, sized from the provider's own rate-limit headers and adjusted continuously (up under headroom, down on 429s, overload, or rising latency), so parallel work stays under the provider's limits instead of retrying through 429s. The interactive turn goes first when the budget is tight; the live pacing shows on the /usage page. No settings.
