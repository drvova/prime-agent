- The kernel's MCP, rizin and web functions are fewer: `mcp-list` with `#:kind` (`"tools"`, `"resources"`, `"templates"`, `"prompts"`, `"connections"`, `"catalog"`) replaces `mcp-tools`, `mcp-resources`, `mcp-prompts`, `mcp-status` and `mcp-plugins`; `rz-cmd #:json #t` replaces `rz-cmdj`; `web-capture` with `#:format "png"` or `"pdf"` replaces `web-screenshot` and `web-pdf`; and `web-read #:select` replaces `web-extract`. The old names still work for one release and print a one-line deprecation notice the first time each is used.
