- The kernel's event, messaging, subagent, MCP and todo functions are fewer and clearer: `event-define`, `event-remove` and `event-list` also handle scheduled jobs and heartbeats (`#:kind`), `agent-send` sends to one member (`#:to`, a name or a roster row) or everyone (`#:all`), `event-wait` waits for a message, `agent-roster` lists, reads and previews the family, `rlm-spawn #:root` creates a top-level session, `rlm-delete` and `end-turn` replace their `rlm-` forms, `mcp-tools`, `mcp-call`, `mcp-status`, `mcp-resources`, `mcp-prompts` and `mcp-plugins` cover every MCP read, and `todo-set #:merge` changes items in place; the `schedule-*`, `rlm-heartbeat-*`, `event-source-*`, `agent-message-*`, `agent-observe-*`, `rlm-list-subagents`, `rlm-create-session`, `rlm-delete-subagent`, `rlm-end-turn`, the older `mcp-*` names and `todo-update` are gone.
