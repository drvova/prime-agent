- The runtime daemon: `prime-agent --mode daemon` starts the event-driven runtime daemon on its own socket (`daemon2.sock` beside the daemon's), serving the new client protocol for session create, stop, rename, delete, model and effort changes, fork, label, export, the session list, snapshots and transcript pages; one runs per agent dir, and it never holds a session an old daemon left running holds (their session leases keep them apart).
