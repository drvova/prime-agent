- An opt-in runtime daemon: with `PRIME_AGENT_RUNTIME_DAEMON=1` or `"daemon": "runtime"` in the global settings, `prime-agent --mode daemon` starts the event-driven runtime daemon on its own socket (`daemon2.sock` beside the daemon's), serving the new client protocol for session create, stop, rename, delete, model and effort changes, fork, label, export, the session list, snapshots and transcript pages; it shares sessions with the existing daemon through their session leases, so the two never hold the same session, and one runs per agent dir. Without the flag nothing changes.
