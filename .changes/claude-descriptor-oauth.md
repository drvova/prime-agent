- Providers in `models.json` can sign in with OAuth: an `auth` block with `"strategy": "oauth"` declares the authorization, device, and token endpoints, and `login <provider>` (or `/login`) signs in through the browser with PKCE, or with a device code over SSH. The access token is refreshed before it expires, and a failed refresh asks you to sign in again. `logout <provider>` removes the stored credential.
