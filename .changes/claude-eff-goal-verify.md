- Goals can now verify completion: `goal.create(..., check="cargo test -q")` runs the command before `goal.complete()` settles the goal (a failure keeps the goal active and sends the command, exit code, and output tail to the next turn), `verify="judge"` adds a cheap read-only judge that must cite evidence from the conversation, and `max_cost_usd` caps a goal's dollar spend; goal token budgets now count cache writes like autonomous budgets do.
