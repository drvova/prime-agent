- Prompt caching is cheaper on Anthropic and Claude-on-Bedrock models: the system prompt's shared static layers are cached as their own block, so new sessions and subagents read them instead of writing them again; a new `cacheRetention` setting (`short` or `long`, overridden by `PI_CACHE_RETENTION`) picks the cache lifetime, and `cacheWarming` (`active` by default, `idle`, or `off`) keeps a waiting session's cache alive when that is expected to save money.
