- The agent's kernel is now a Scheme interpreter built into Prime Agent: the model works through one `eval` tool, sessions run inside the daemon (a new session's first call is about three times faster on a running daemon), nothing installs Python or uv any more, and a crashed session or daemon is shown, restarted and resumed automatically. Python skills and the Python REPL are gone; saved sessions still open.
- A new session in a project you have used before starts its first turn sooner: the workspace checkpoint re-reads only the files that changed instead of every file.
- `fs-read` now pages the file's likely next reads (its test file, its imports, and its callers from the symbol index) out as handles named in the result, so the model can read a neighbour with `ctx-page` without another lookup; per project it learns whether those handles get used and scales the prefetch down when they do not.
- Paged-out and thinned outputs now preview their most informative lines instead of just the head and tail: error/warning/failure lines and their locations, the first occurrence of each distinct line with repeats folded into `×N`, and lines with rare tokens, within the same budget; per project it learns which line patterns are always noise (banners, progress bars, timestamps) and folds them into one marker.
- The agent can drive the Rizin reverse-engineering framework you have installed: `(rz-open "/path/binary")` starts a `rizin` session, `(rz-cmd s "pdf @ main")` and `(rz-cmdj s "aflj")` run its commands (analysis, disassembly, RzIL, patching, and the debugger with `#:debug #t`), and `(api-help "rizin")` maps them. A command is interrupted when its time limit passes or its cell is stopped, and every session and the program it debugs is killed when the kernel ends. It needs `rizin` 0.7.4 or newer on your PATH; without it `rz-open` says how to install it.
- A distribution build's first launch imports the official configuration again: starting up no longer creates the agent directory before that import runs.
- The agent's `bash` commands now run on a bash-compatible shell built into Prime Agent on Linux, macOS and Windows, instead of starting `/bin/bash` for each one: `ls`, `cat`, `grep`, `sed`, `find`, `sort`, `xargs`, `jq` and 27 more utilities run inside it, only the programs a command names (`git`, `cargo`, ...) are started, a short command returns sooner, and `bash` and `jq` work on a machine that has neither (Windows without Git Bash). Scripts that depend on the system shell (signal traps, `$$` as a process id, `ulimit`) can have it back with `"shell": "system"` in settings; a `shellPath` you already set keeps selecting your shell.
- A misspelt option no longer does nothing: the agent's kernel functions refuse an option they do not accept (`#:timout-ms` for `#:timeout-ms`, an unknown key of a `bash` or `fs-*` options hash, an argument an MCP tool's schema does not list), an option given twice or without a value, and a wrong number of arguments, before anything runs, and the error names the accepted options and the nearest one so the agent corrects the call in one step.
