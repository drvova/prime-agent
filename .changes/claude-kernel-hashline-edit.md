- The Python REPL can now edit files by anchor: `fs.read(path)` tags every line as `12:abc|text`, and `fs.edit(path, [{"replace": "12:abc", "text": "..."}])` replaces, deletes or inserts by pointing at those anchors instead of retyping old text; if the file changed since it was read, the whole patch is rejected with the current lines and nothing is written, and line endings, the final newline and the encoding are kept.
