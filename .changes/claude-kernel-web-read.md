- The Python REPL can now read web pages: `web.read(url)` (or `web.read(search_source)`) returns markdown with the page's heading anchors and links, reading arXiv papers (HTML rendering or PDF by page), GitHub files, READMEs, issues and pull requests, and Stack Overflow questions with their voted answers from their structured sources; `section=` returns one heading's span or a code view's line range.
