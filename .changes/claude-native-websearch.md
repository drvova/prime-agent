- Web search is now built in and works without an API key: `web.search(...)` in the Python REPL (and the websearch skill) runs on a native engine whose default `auto` provider uses any keyed provider configured via `/mcp` (Serper, You.com Eco, Brave, Tavily, Exa, Kagi, Perplexity, Parallel, Jina, Firecrawl) and otherwise falls back through keyless engines (DuckDuckGo, Startpage, Mojeek, Ecosia); an unset `webSearchProvider` now means `auto` instead of Serper, while explicit `serper`/`eco` settings keep working as before.
