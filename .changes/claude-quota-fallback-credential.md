- A provider's `models.json` `auth` block can name `fallback` providers: when its usage quota is spent (a reset beyond the retry cap), the request retries once, right away, with the first listed provider's credential that serves the same model, and later requests use it until the reset. For example, `"opencode": { "auth": { "strategy": "api-key", "fallback": ["opencode-go"] } }` serves an exhausted OpenCode free tier with a stored OpenCode Go key. Providers without `fallback` behave as before.
