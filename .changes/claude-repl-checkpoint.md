- The Python REPL can now take workspace checkpoints before risky edits: `await checkpoint.create("before refactor")` snapshots the session's files in prime-agent's own shadow store (never the project's git history) and `checkpoint.list()` lists them. `checkpoint.restore(id)` puts the files back, but only once you turn on the new `replCanRestoreCheckpoints` setting (off by default, global settings only), only for checkpoints that session took, and only after you confirm the listed changes.
