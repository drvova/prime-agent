- The drvova build (`prime`) now copies your chats, their subagent runs, and the harness memory from `~/.prime/agent` into `~/.prime/agent-fork` once, in the background, so `/resume` shows them. It copies only, never moves, links, or overwrites a file. It also fills in configuration files the fork lacks (MCP servers, models, system prompts). `prime import-sessions` runs the import again, and `--skip` turns it off.
