- Distribution builds (such as the drvova build's `prime`) keep their own data directory, `~/.prime/agent-<variant>`, and their own daemon endpoints, so `--continue`, `--resume` and `/resume` never show or reopen the official build's or the TypeScript Prime Agent's sessions; the first run imports settings, logins, custom models, keybindings, skills, prompts and themes from `~/.prime/agent` once, never the sessions. The official build is unchanged.
