- Rewinds now undo code changes too: Prime Agent snapshots the workspace at every turn (in a separate git store under `~/.prime/agent/checkpoints`, never your project's repository), so picking a point in the session tree (double Esc or `/tree`) also puts the files back the way they were there. Picking the point you left brings its files back. Files edited outside the session since the last turn are left alone and listed.
