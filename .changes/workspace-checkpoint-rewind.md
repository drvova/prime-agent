- Rewinds can now undo code changes too. Prime Agent snapshots the workspace's files at every turn (in a separate git store under `~/.prime/agent/checkpoints`, never your project's own repository), so picking a prompt in the session tree (double Esc or `/tree`) offers "Rewind conversation + code changes" alongside "Rewind conversation only". `/undo` rewinds the last turn with its file changes and puts the prompt back in the editor, and `/redo` returns to where the undo left. Files edited outside the session since the last turn are left alone and listed.
