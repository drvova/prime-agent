# events: event sources, publications, and subscriptions

The daemon keeps one event bus for every session it runs. An event source is a service with a schema: a name (`deploy.finished`) and a JSON object schema for its payloads, owned by the session that defined it, which is the only session that publishes or removes it. A session that subscribes gets a new turn for each matching event, so it reacts instead of polling: start the work, subscribe to the event that ends it, and end the turn. Sources and subscriptions persist across daemon restarts; a subscription whose session no longer exists is dropped at its next event. A headless run (`--print`, `--mode json`) keeps its own bus for the sessions the run runs, with the same rules and the same deliveries: an event reaches a subscriber only while the run runs it, and a subagent spawned inline in such a run has no bus (its calls raise).

- `(event-source-define name schema #:description #:timer #:watch)`: define, or redefine, a source this session owns; the record `{name, description, schema, ownerSessionId, ownerName, definedAt, publishedCount}`, with `timer` or `watch` for those kinds (see Source kinds). `name` is 1 to 64 lowercase letters, digits, `.`, `-` and `_`, starting with a letter, and names one source of any kind. `schema` is a JSON object schema as a hash (`(hash 'type "object" 'properties (hash 'env (hash 'type "string")) 'required (list "env"))`), at most 16 KiB; for a timer or a watch it is `#f`. Another session's source cannot be redefined, and a timer or a watch is not redefined another way: remove it first. A session owns at most 32 sources, of every kind
- `(event-source-remove name)`: remove one of this session's sources and every subscription to it: `{removed, subscriptionsRemoved}`
- `(event-publish source payload)`: publish one event of a source this session owns: `{eventId, matched}`, where `matched` counts the subscriptions it is delivered to. `payload` is a hash checked against the source's schema (an invalid one raises with the validation errors, and nothing is delivered), at most 8 KiB as JSON. The call does not wait for the deliveries; each subscription's `deliveredCount` (`event-list`) counts what reached its session. Your own subscriptions never receive your own events
- `(event-subscribe source prompt #:filter #:delivery-mode #:label)`: subscribe this session to a defined source; the subscription `{id, source, filter, prompt, deliveryMode, label, sessionId, cwd, createdAt, deliveredCount}`. Each matching event starts a turn that reads `[agent-message from event <source>]` followed by the event id, `prompt` (at most 4,000 characters), and the payload as JSON. `#:filter` is a hash of payload keys and the values they must equal (`(hash 'env "prod")`), naming only properties the schema declares. In a headless run `source` may instead be a topic filter (any text with a `/`; `+` matches one level, `#` the rest): `"source/+/published"` hears every source's publications, and the filter's keys are the event payload's `#:delivery-mode` is `"follow_up"` (the default: after a running turn) or `"steer"` (into it, at its next step). A saved session that is not running is woken for its event. A publisher that wakes the same idle session too often is refused by that session's wake budget, as agent messages are. A session holds at most 64 subscriptions
- `(event-unsubscribe subscription)`: cancel one of this session's subscriptions, by id or by the record `event-subscribe` returned; the cancelled subscription
- `(event-list)`: every source on the bus and this session's subscriptions: `{sources, subscriptions}`

## Source kinds

A source defined without `#:timer` or `#:watch` is a bus source: its owner publishes it. In a headless run a source may instead publish its own events, under a payload schema fixed by its kind (`event-list` shows it). At most one of `#:timer` and `#:watch` is given, `schema` is `#f`, and `event-publish` refuses it. It runs while a subscription hears it, and only in this run: it is not kept, and it ends with the run. The daemon's bus defines bus sources only. Long-lived timer and watch sources, and scheduled wakes of saved sessions, are not available in this run.

- Timer: `#:timer` is a hash of exactly one of `'every` (`"30s"`, `"5m"`, `"1h30m"`; at least 1 s), `'cron` (five fields in UTC, `"0 9 * * 1-5"`, or `"@hourly"`-style) and `'at` (one ISO time, `"2026-12-01T09:00:00Z"`, fired once, at once when it has passed). It fires on `timer/<name>` with the payload `{scheduledFor, firedAt}` (Unix milliseconds); missed fires collapse into one. `(event-source-define "tick" #f #:timer (hash 'every "5m"))`, then `(event-subscribe "tick" "Check the build.")`
- Watch: `#:watch` is a hash of `'path` (a folder or file that exists, under this session's working directory: relative paths resolve against it, and links are followed), and optionally `'glob` (a name pattern such as `"*.rs"`, or a path pattern relative to the folder with `/`), `'recursive` (`#t`, the default: subfolders too) and `'debounce-ms` (200 by default: a burst of changes within it is one event). It publishes `source/<name>/changed` with `{paths, kinds}` (absolute paths; kinds among `create`, `modify`, `rename`, `remove`, `other`, `any`), and `source/<name>/error` with `{error}` when watching fails. `(event-source-define "src" #f #:watch (hash 'path "src" 'glob "*.rs"))`
- Subscribing by name hears the source's topics: `timer/<name>` for a timer, `source/<name>/#` otherwise. Each event starts a turn that reads `[agent-message from event <name>]` and the payload, as for a bus source. `(event-source-remove name)` stops the source and removes the subscriptions to it
