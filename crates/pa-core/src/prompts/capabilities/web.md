# web: search the web and read pages

Native search and reading; API keys stay on the host and none is needed. Both calls end with their cell.

- `(web-search query #:provider #:num-results #:recency #:timeout)`: `{provider, label, answer, sources, citations, relatedQuestions, failures, notes, text}`. `text` is the readable numbered list (with any synthesized answer and fallback notes); each source is `{title, url, snippet, publishedDate, author}`; `answer` is set by answer-synthesizing providers. `site:`, `-site:`, `before:`/`after:`, `intitle:`, `filetype:`, quoted phrases, and `OR` in the query are honored. `#:provider` is `"auto"` (keyed providers the user configured, then keyless engines, falling back when one fails or finds nothing) or one of `serper`, `eco`, `brave`, `tavily`, `exa`, `kagi`, `perplexity`, `parallel`, `jina`, `firecrawl`, `searxng`, `duckduckgo`, `startpage`, `mojeek`, `ecosia`, `hackernews`, `public`; omitted, the `/settings` choice. `#:recency` is `"day"`, `"week"`, `"month"`, or `"year"`; `#:timeout` is seconds per request. Raises when every provider fails
- `(web-read source #:max-chars #:section #:timeout)`: read a URL as markdown; prefer it over fetching with `bash`. Returns `{url, finalUrl, title, contentType, method, markdown, outline, links, section, truncated, totalChars, notes, text}`; `text` is the readable rendering. `source` is a URL or anything carrying one under `'url`: a search source, a `links` entry (`{text, url}`), an `outline` heading (`{level, text, anchor, url}`). arXiv papers, GitHub files, READMEs, issues and PRs, and Stack Exchange questions (with voted answers) come from their structured sources; HTML is made readable; PDFs split into `## Page N {#page=N}` sections. Cite with a heading's `url` or `finalUrl#anchor`. A long page is cut at `#:max-chars` (default 20000) with a note: read one span with `#:section` (an outline anchor, a heading's text, or `"L10-L40"` for a code view). `#:timeout` is the whole read's deadline in seconds (default 30)
