# web: search the web, read pages, crawl sites

Native search and reading; API keys stay on the host and none is needed. Every call ends with its cell.

- `(web-search query #:provider #:num-results #:recency #:timeout)`: `{provider, label, answer, sources, citations, relatedQuestions, failures, notes, text}`. `text` is the readable numbered list (with any synthesized answer and fallback notes); each source is `{title, url, snippet, publishedDate, author}`; `answer` is set by answer-synthesizing providers. `site:`, `-site:`, `before:`/`after:`, `intitle:`, `filetype:`, quoted phrases, and `OR` in the query are honored. `#:provider` is `"auto"` (keyed providers the user configured, then keyless engines, falling back when one fails or finds nothing) or one of `serper`, `eco`, `brave`, `tavily`, `exa`, `kagi`, `perplexity`, `parallel`, `jina`, `firecrawl`, `searxng`, `duckduckgo`, `startpage`, `mojeek`, `ecosia`, `hackernews`, `public`; omitted, the `/settings` choice. `#:recency` is `"day"`, `"week"`, `"month"`, or `"year"`; `#:timeout` is seconds per request. Raises when every provider fails
- `(web-read source #:max-chars #:section #:timeout #:format #:transform)`: read a URL as markdown; prefer it over fetching with `bash`. Returns `{url, finalUrl, title, contentType, method, markdown, outline, links, section, truncated, totalChars, notes, text}`; `text` is the readable rendering. `source` is a URL or anything carrying one under `'url`: a search source, a `links` entry (`{text, url}`), an `outline` heading (`{level, text, anchor, url}`). arXiv papers, GitHub files, READMEs, issues and PRs, and Stack Exchange questions (with voted answers) come from their structured sources; HTML is made readable; PDFs split into `## Page N {#page=N}` sections. Cite with a heading's `url` or `finalUrl#anchor`. A long page is cut at `#:max-chars` (default 20000) with a note: read one span with `#:section` (an outline anchor, a heading's text, or `"L10-L40"` for a code view). `#:timeout` is the whole read's deadline in seconds (default 30). For an HTML page, `#:format` picks another rendering (from spider's transformations; `method` is then `html-transformed`, and a site route such as GitHub's is skipped for the page itself): `'markdown` (the default, this reader's own), `'commonmark`, `'text` (the words without markup), `'html2text` (laid out as a terminal browser shows it), `'html` (the page's HTML) or `'xml` (the page as well-formed XML); the non-markdown ones are a code view whose `#:section` is a line range. `#:transform` is a hash run on the HTML first: `'readability #t` (the article only), `'main-content #t` (no navigation, header, footer or side panels), `'filter-images #t`, `'filter-svg #t`, `'clean-html #t` (no scripts, styles or attributes), `'root "css"` (only the first match), `'exclude "css"` (drop every match): `(web-read url #:format 'text #:transform (hash 'readability #t))`. A non-HTML page ignores both with a note; a page nested more than 2000 elements deep is refused with them
- `(web-crawl source #:max-pages #:max-depth #:include #:exclude #:max-chars #:subdomains #:sitemap #:render #:mode #:timeout #:budget #:external-domains #:full-resources #:normalize #:retry #:throttle #:warc #:wait-idle #:wait-delay #:wait-selector #:wait-dom #:viewport #:javascript #:actions #:scripts #:block #:init-script #:locale #:timezone #:format #:transform #:extract #:cookies)`: read a site page by page from `source` (a URL or anything carrying one under `'url`). Returns `{url, render, mode, pages, failed, truncated, notes, warc, text}`; each of `pages` has `web-read`'s shape (`title`, `finalUrl`, `markdown`, `outline` with anchors, `links`, ...), `failed` holds `{url, status}` for pages the site answered with an error, `text` is the index (one line per page). It stays on the start host (`#:subdomains #t` adds its subdomains), obeys robots.txt, sends an honest Prime Agent user agent, and goes four requests at a time with a pause between them. What a crawl presents to a site is the user's to set, never a call's: their global `web.crawl` settings can turn off robots.txt (`respectRobotsTxt`), set a `userAgent` or rotate real browser ones (`rotateUserAgent`), add `headers` and `cookies` (sent to the crawled site's hosts only; a rendered crawl's browser sends the headers on the page's own requests and keeps the cookies to the site), send HTTP Basic credentials (`auth`, plain crawls only, to the site's hosts; you never see them), route requests through `proxies` (`http`, `https`, `socks5`, `socks5h`; several are taken in turn), and make a rendered crawl hide its automation (`stealth`) and present a real browser's fingerprint (`fingerprint`). The environment section names those that are on; a setting that is not valid fails the crawl with the setting's name, which only the user can fix. A change takes effect from the next crawl. robots.txt and the sitemap are read without the headers, cookies and credentials. `#:max-pages` (default 20, at most 200) and `#:max-depth` (links from the start page, default 3, at most 25) bound it; `#:include` and `#:exclude` are URL regexes (one string or a list) a followed link must match / must not match; `#:max-chars` cuts each page's markdown (default 8000); `#:sitemap #t` also reads the site's `/sitemap.xml`; `#:render #t` loads each page in a local headless Chrome or Chromium (found on `PATH`, in its usual install place, or named by `CHROME_PATH`; an error says how to install one when there is none) so script-built pages read as a browser shows them (`#:mode 'render` says the same); `#:mode 'smart` reads every page over HTTP and loads in the browser only a page whose HTML says it needs JavaScript (an app shell, a framework's client bundle, a `<noscript>` asking for it), which is much faster than rendering a mostly static site: `(web-crawl "https://docs.example.org/" #:mode 'smart)`; the browser options below work with it too; `#:timeout` is the whole crawl's deadline in seconds (default 60, at most 600), after which it returns what it has with a note. A page past the result's 400000-char budget carries `'handle` (read it with `ctx-page`) and an empty `markdown`. Reach: `#:budget` is a hash of path prefix to pages (`(hash "/blog" 5 "*" 50)`; `"*"` is every path, capped by `#:max-pages`); `#:external-domains` names other hosts crawled as part of the site (one host or a list; no patterns); `#:full-resources #t` also follows the stylesheet, script and media links a crawl skips (each read as `web-read` would); `#:normalize #t` treats URLs differing only in a trailing slash and the like as one page; `#:retry` (0-3) retries a failed page; `#:throttle 'auto` paces each host by its measured response time (slower hosts get longer pauses, never shorter than the fixed one); `#:warc "path"` appends every response the crawl received (pages and failures, headers and bodies) as a WARC record to that file (relative: under the session's working directory) for an archive or a replay tool, and `warc` in the result is `{path, records}`: `(web-crawl "https://example.org/" #:max-pages 50 #:warc "archive/example.warc")`. With `#:render #t` or `#:mode 'smart` only (refused otherwise): `#:wait-idle` / `#:wait-delay` (seconds, at most 60) wait for the network to go idle / a fixed time; `#:wait-selector` / `#:wait-dom` (CSS) wait for an element / for the DOM under it to stop changing; `#:viewport` is `(list width height)`; `#:javascript #f` keeps the pages' scripts from running; `#:scripts` is a hash of URL or path to JavaScript evaluated on that page; `#:actions` is a hash of URL or path to a list of automation steps run in order on that page before it is read, each in spider's form: `(hash 'Click "css")`, `(hash 'ClickAll "css")`, `(hash 'Fill (hash 'selector "css" 'value "text"))`, `(hash 'Type (hash 'value "text"))`, `(hash 'Evaluate "js")`, `(hash 'Wait ms)`, `(hash 'WaitFor "css")`, `(hash 'WaitForAndClick "css")`, `(hash 'ScrollY px)`, `(hash 'InfiniteScroll times)`, `"WaitForNavigation"`, `(hash 'Screenshot (hash 'full_page #t 'omit_background #f 'output "shot.png"))` (a relative `output` is under the session's directory), and the rest of spider's `WebAutomation` steps; `#:block` lists what the browser refuses to load, kinds `'images` (and media and fonts), `'stylesheets`, `'scripts`, `'analytics`, `'ads` (spider's built-in ad filter list) and URL patterns (substrings or `*` globs), first-party or not: `#:block '(images stylesheets ads "*/tracker.js")` makes a crawl of a heavy site faster; `#:init-script` is JavaScript run in every document before the page's own scripts (`"window.__CONSENT__ = true;"`); `#:locale` (`"de-DE"`) and `#:timezone` (`"Europe/Berlin"`) are what the pages see; `#:cookies 'session` (the default) keeps cookies across this session's browser loads as a browser does: each page starts with the cookies earlier rendered crawls, `web-screenshot`s, `web-pdf`s and rendered `web-extract`s of this session left for its URL, and the cookies it ends with are kept for the next (a login or consent made by `#:actions` in one crawl holds in the next); they live in memory only, never on disk or in a result, and end with the session (plain HTTP reads do not use them); `#:cookies #f` starts empty and keeps nothing. Every page: `#:format` and `#:transform` shape each HTML page as `web-read`'s do; `#:extract` is a selectors hash as `web-extract` takes, and each HTML page then carries `'extract` (each name's values; a page whose extraction fails says why in its notes): `(web-crawl "https://shop.example/" #:include "/item/" #:extract (hash 'name "h1" 'price ".price"))`. A long crawl is a long cell: past the cell's timeout it goes on in the background and a `[cell-done]` notice brings its value (see the cells reference); a crawl on a schedule is a `schedule-add` prompt that calls it. Example: `(define docs (web-crawl "https://docs.example.org/guide/" #:include "/guide/" #:max-pages 40))` then `(map (lambda (p) (hash-ref p 'title)) (hash-ref docs 'pages))`
- `(web-extract source selectors #:render #:mode #:timeout #:cookies)`: the values spider's selectors find on one page: `selectors` is a hash of names to a CSS selector or an XPath expression (or a list of them), and the result is a hash of each name to the list of values found (empty when nothing matched). A CSS match gives the element's text, or a `meta`'s `content`, a `link`'s `href`, a `script`'s `src`, an `img`'s `[src]("alt")`; an XPath gives the string of what it selects first (`"//a/@href"`, `"string(//h1)"`, `"count(//li)"`), read from the page made well-formed XML. `source` is a URL (or anything carrying one under `'url`), read as a one-page crawl (robots.txt and the user's `web.crawl` identity apply; `#:render #t` or `#:mode 'render` / `'smart` loads it in the browser; `#:timeout` in seconds), or HTML text starting with `<`, which is read as given; `#:cookies` is `web-crawl`'s. A selector that is neither CSS nor XPath is refused; at most 100 names, 1000 values per name, each cut at 10000 chars, and more than 400000 chars in all fails with a note to narrow them. Example: `(web-extract "https://example.org/" (hash 'title "h1" 'links "a" 'first-link "//a/@href"))`
- `(web-screenshot source path #:full-page #:viewport #:wait #:init-script #:timeout #:cookies)`: load `source` (a URL or anything carrying one under `'url`) in a local headless Chrome or Chromium (found as a rendered crawl finds it) and save a PNG at `path` (a relative path is under the session's working directory). Returns `{url, finalUrl, title, path, bytes}`. `#:full-page #t` captures the whole page rather than the viewport; `#:viewport` is `(list width height)`; `#:wait` is seconds to wait after the load (at most 60); `#:init-script` is JavaScript run in the document first; `#:timeout` is the deadline in seconds (default 30, at most 120). The user's `web.crawl` user agent, headers, cookies and first proxy apply, and `#:cookies` is `web-crawl`'s (the session's cookies for the page, kept after it). Look at it with `attach-image` when the model can see images. Example: `(web-screenshot "https://example.org/" "shots/home.png" #:full-page #t)`
- `(web-pdf source path #:landscape #:background #:viewport #:wait #:init-script #:timeout #:cookies)`: load `source` as `web-screenshot` does and print it to a PDF at `path`. Returns `{url, finalUrl, title, path, bytes}`. `#:landscape #t` prints landscape; `#:background #t` prints background colours and images. Example: `(web-pdf "https://example.org/report" "report.pdf" #:background #t)`
