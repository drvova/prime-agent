# web: search the web, read pages, crawl sites

Native search and reading; API keys stay on the host and none is needed. Every call ends with its cell.

- `(web-search query #:provider #:num-results #:recency #:timeout)`: `{provider, label, answer, sources, citations, relatedQuestions, failures, notes, text}`. `text` is the readable numbered list (with any synthesized answer and fallback notes); each source is `{title, url, snippet, publishedDate, author}`; `answer` is set by answer-synthesizing providers. `site:`, `-site:`, `before:`/`after:`, `intitle:`, `filetype:`, quoted phrases, and `OR` in the query are honored. `#:provider` is `"auto"` (keyed providers the user configured, then keyless engines, falling back when one fails or finds nothing) or one of `serper`, `eco`, `brave`, `tavily`, `exa`, `kagi`, `perplexity`, `parallel`, `jina`, `firecrawl`, `searxng`, `duckduckgo`, `startpage`, `mojeek`, `ecosia`, `hackernews`, `public`; omitted, the `/settings` choice. `#:recency` is `"day"`, `"week"`, `"month"`, or `"year"`; `#:timeout` is seconds per request. Raises when every provider fails
- `(web-read source #:max-chars #:section #:timeout)`: read a URL as markdown; prefer it over fetching with `bash`. Returns `{url, finalUrl, title, contentType, method, markdown, outline, links, section, truncated, totalChars, notes, text}`; `text` is the readable rendering. `source` is a URL or anything carrying one under `'url`: a search source, a `links` entry (`{text, url}`), an `outline` heading (`{level, text, anchor, url}`). arXiv papers, GitHub files, READMEs, issues and PRs, and Stack Exchange questions (with voted answers) come from their structured sources; HTML is made readable; PDFs split into `## Page N {#page=N}` sections. Cite with a heading's `url` or `finalUrl#anchor`. A long page is cut at `#:max-chars` (default 20000) with a note: read one span with `#:section` (an outline anchor, a heading's text, or `"L10-L40"` for a code view). `#:timeout` is the whole read's deadline in seconds (default 30)
- `(web-crawl source #:max-pages #:max-depth #:include #:exclude #:max-chars #:subdomains #:sitemap #:render #:timeout)`: read a site page by page from `source` (a URL or anything carrying one under `'url`). Returns `{url, render, pages, failed, truncated, notes, text}`; each of `pages` has `web-read`'s shape (`title`, `finalUrl`, `markdown`, `outline` with anchors, `links`, ...), `failed` holds `{url, status}` for pages the site answered with an error, `text` is the index (one line per page). It stays on the start host (`#:subdomains #t` adds its subdomains), always obeys robots.txt, sends an honest Prime Agent user agent, and goes four requests at a time with a pause between them. `#:max-pages` (default 20, at most 200) and `#:max-depth` (links from the start page, default 3, at most 25) bound it; `#:include` and `#:exclude` are URL regexes (one string or a list) a followed link must match / must not match; `#:max-chars` cuts each page's markdown (default 8000); `#:sitemap #t` also reads the site's `/sitemap.xml`; `#:render #t` loads each page in a local headless Chrome or Chromium (found on `PATH`, in its usual install place, or named by `CHROME_PATH`; an error says how to install one when there is none) so script-built pages read as a browser shows them; `#:timeout` is the whole crawl's deadline in seconds (default 60, at most 600), after which it returns what it has with a note. A page past the result's 400000-char budget carries `'handle` (read it with `ctx-page`) and an empty `markdown`. Example: `(define docs (web-crawl "https://docs.example.org/guide/" #:include "/guide/" #:max-pages 40))` then `(map (lambda (p) (hash-ref p 'title)) (hash-ref docs 'pages))`
