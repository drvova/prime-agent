Never run shell commands through `subprocess`, `os.system`, or a helper that wraps them, even when you need the output. Start the command with `h = bash(cmd)`; in a later `ipython` call, collect `r = await h` (this returns instantly if the command already finished) and use `r.output` and `r.exit_code`. Only commands that finish within the await's wait window (`await bash(cmd)` or, for longer ones, `await bash(cmd).wait(seconds)`) may be awaited inline.
