Never run shell commands through Steel's process functions (`command`, `spawn-process`) or a helper that wraps them, even when you need the output. Run the command with `(define r (bash cmd))` and use `(hash-ref r 'output)` and `(hash-ref r 'exit-code)`. A command that takes longer than the wait window comes back as a snapshot with `running` `#t`: do not wait on it in a loop; end the turn and collect `(bash-wait r)` on the `[bash-done]` notice. Only for a command known to finish soon may you ask for a longer wait up front, `(bash cmd (hash 'wait-ms 120000))`.
