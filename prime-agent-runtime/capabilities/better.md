- `better(task: str, *, cwd: str | None = None, mode: str = "deepen") -> str`: a read-only helper on your own model rewrites `task` into the deeper prompt a top professional would ask for, grounded in the repository; `mode="brief"` instead checks a delegation brief against the repository from `cwd` (every path, name, and command must exist or run read-only), fixes what is wrong, and returns it unchanged when nothing needs fixing. A rewrite or brief ends with an `<acceptance>` block (`run: <command>`, `exists: <path>`, `grep: <path> <text>` per line); a prompt carrying one has the host run those checks when your turn ends, and a failed round arrives as a notice to fix and continue from.
- `better.checks() -> dict`: where the armed acceptance checks stand (`status` is `none`, `pending`, `passed`, or `failed`; `last` is the latest round's evidence)
- `better.evidence(handle: str) -> dict`: one round's per-check results (`passed`, `reason`) by its `out:<id>` handle
