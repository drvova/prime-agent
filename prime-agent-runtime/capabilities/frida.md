## Frida

`frida.*` drives Frida dynamic instrumentation. Instrument only processes and apps the user owns or is authorized to test. The pinned frida and frida-tools install into the kernel venv in the background after its first setup; until then calls raise `frida.FridaInstalling`, and a platform without a frida wheel (or a Python the host does not manage) raises `frida.FridaUnavailable` with the reason and the install command. Attaching can need privileges (Linux ptrace scope, root or developer mode on a phone); Frida's errors surface unchanged. `device` is `None` (local), `"usb"`, `"remote"`, a device id, or a `FridaDevice`. The kernel detaches every session when it shuts down, and a session that spawned its target kills it on detach. The bound `frida` is this module; `import frida as fr` reaches the raw bindings.

- `frida.devices() -> list[FridaDevice]`: `id`, `name`, `type` (`frida-ls-devices`)
- `frida.add_remote(address: str, *, certificate=None, origin=None, token=None, keepalive_interval=None) -> FridaDevice`: connect a frida-server at `host[:port]`
- `frida.ps(*, device=None, applications: bool = False) -> list[FridaProcess] | list[FridaApplication]`: `pid`, `name`; applications add `identifier` (`pid` 0 when not running)
- `frida.kill(target: int | str, *, device=None) -> None`: by pid or process name
- `frida.attach(target: int | str, *, device=None, spawn: bool = False, args: list[str] | None = None, pause: bool = False) -> FridaSession`: a pid or process name; with `spawn=True`, a program path or app identifier started with `args` and resumed after its first `load()` unless `pause=True` (the `frida` CLI)
  - `FridaSession`: `await s.load(source: str, *, name=None, runtime=None) -> FridaScript`, `await s.resume()`, `await s.detach()`, `.pid`, `.detached_reason`
  - `FridaScript`: `send()` messages, errors and `console.log` lines go to a bounded buffer (the newest 1000; `.dropped` counts the rest), never into a cell's output: `.messages(n=None) -> list[FridaMessage]` (`seq`, `type` send/error/log, `payload`, `data`), `.tail(n=20) -> str`, `await .wait(predicate=None, *, timeout=30) -> FridaMessage | None` (the next one; a wait past the cell's window continues as a background cell), `await .call(export, *args)` (`rpc.exports`), `.post(message)`, `await .unload()`
- `frida.trace(target, *, include=(), exclude=(), include_modules=(), exclude_modules=(), include_imports=(), add=(), objc=(), exclude_objc=(), swift=(), exclude_swift=(), java=(), exclude_java=(), debug_symbols=(), device=None, spawn=False, args=None, duration_s=None) -> FridaTrace`: `frida-trace`'s `-i -x -I -X -t -a -m -M -y -Y -j -J -s` through frida-tools' Tracer; `.events(n)`, `.tail(n)`, `await .wait(...)` (`FridaTraceEvent(ms, thread_id, depth, function, message)`, None once it ended), `.warnings`, `await .stop()`; it stops itself after `duration_s`
- `frida.discover(target, *, duration_s: float, device=None, spawn=False, args=None) -> FridaDiscovery`: `.threads`, `.functions` (`FridaHotFunction(module, name, address, calls)`, the most called first) (`frida-discover`)
- `frida.compile(entrypoint: str, *, project_root=None, output=None, **options) -> str`: the `frida-compile` bundle
- `frida.tool(name: str, *args: str, device=None) -> BashHandle`: any frida-tools console script as a `bash()` job; `frida.ls`, `rm`, `pull`, `push`, `join`, `itrace`, `strace`, `create`, `apk`, `pm` (`*args, device=None`) run `frida-<name>`
- `frida.graft(binary: str, *, output=None, instrument=(), ingest_function_starts=False, ingest_imports=False, transform_lazy_binds=False) -> BashHandle`: `gum-graft` on a Mach-O binary, in place or into a copy at `output`; it is a separate Frida release binary (macOS) that must be on PATH
