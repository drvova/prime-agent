- `rlm.hypotheses(task: str, approaches: list[str], *, check: str | Callable[[Path], Any], timeout_ms: int = 1_800_000, better: bool = False) -> Hypotheses`: try 2-6 approaches at once, one child per approach in its own `worktree`; once they settle, runs `check` in each checkout (a shell command: exit 0 passes; or a callable on the path) and returns the ranked table (passing first, then smaller diff). Each row's `diff` is a handle (`.text` is the patch); every worktree but `table.winner`'s (`None` when nothing passed) is removed. Bring the winner home with `worktree.merge(table.winner.worktree)`, then `worktree.remove` it
